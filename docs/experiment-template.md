# Experiment title

One sentence explaining the task. Add a preview and link to the selected recording when available.

## Setup and outcome

- **Robot and simulator:** model, source, simulator version.
- **Task:** starting conditions, target behavior, success criteria.
- **Recorded outcome:** what happened and which checks passed, failed, or were not run.
- **Limitations:** prepared grasps, known coordinates, tuned contacts, fixed layouts, or other relevant assumptions.

## Model involvement

- **Model:** reported label and exact version/settings when recorded; otherwise unknown.
- **Role:** environment authoring, controller authoring, guided planning, or live control.
- **Observations:** camera images, simulator state, reports, or a documented combination.
- **Tools and actions:** what the model could inspect, execute, or change.
- **Task brief:** original prompt if available and suitable to share; otherwise a clearly labeled summary.
- **Human guidance:** changes to the setup, strategy feedback, and selection of attempts.

## Run and inspect

Provide tested commands for installation, environment reset, controller execution, validation, and replay/rendering. State the tested platform, expected runtime, and required graphics support. Explain whether each command runs new physics, replays stored states, or makes new model calls.

## Recorded artifacts

Link the selected video, trajectory, initial state, and result report. Identify the code revision, environment version, dependency versions, and seed where applicable. Include checksums for downloadable assets.

State playback speed, cuts, holds, overlays, and other presentation edits. Keep the original recorded trajectory distinct from the edited video.

## Observations and failures

Describe useful findings and representative failures. Separate measured results from hypotheses. If there was no systematic trial set, say so instead of reporting a success rate or general capability ceiling.

## Asset credits

List third-party robot models, meshes, reference images, and other assets with their sources and applicable licenses. Include required notices with distributed assets.
